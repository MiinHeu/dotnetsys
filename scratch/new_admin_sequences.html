Sequence Diagram — Lấy dữ liệu cho các ô hiển thị tổng quát (Parallel Fetching & Polling)
sequenceDiagram autonumber participant Admin as 👨‍💼 Quản Trị Viên participant UI as 💻 Dashboard participant ADM as 🌐 AdminController participant TRK as ⚙️ ConnectionTracker participant POI as 🌐 PoiController participant DB as 🗄️ ApplicationDbContext Admin->>UI: Truy cập trang Dashboard par Lấy thống kê chung (Visits, Devices, POIs, Tours) UI->>ADM: GET /api/admin/summary activate ADM ADM->>DB: Truy vấn Count(Pois, Tours, Devices, Visits) ADM->>DB: Pois.Where(Owner!=null).GroupBy(Owner) DB-->>ADM: Dữ liệu đếm tổng & Cơ cấu chủ quán ADM->>TRK: Gọi GetOnlineCount() (Lấy số liệu từ RAM) TRK-->>ADM: activeUsers ADM-->>UI: return { totalPois, totalTours, activeUsers, ownerStats... } deactivate ADM and Lấy dự phòng (Fallback) UI->>POI: GET /api/poi?lang=vi POI-->>UI: List[Poi] end UI->>UI: Tính toán & xử lý fallback nếu summary lỗi UI-->>Admin: Render Thẻ màu (Quán ăn, Lộ trình, Cài đặt, Lượt nghe, Online) loop Polling mỗi 10 giây (React Query) UI->>ADM: GET /api/admin/summary (Background refetch) ADM->>TRK: GetOnlineCount() ADM-->>UI: Cập nhật activeUsers mới UI-->>Admin: Render chấm xanh nhấp nháy báo hiệu thiết bị Online end
