Tổng Quan Dự Án

Tầm nhìn: Khách du lịch đi dạo phố ẩm thực Vĩnh Khánh. Điện thoại họ tự động phát thuyết minh bằng ngôn ngữ của họ khi đến gần một quán ăn — không cần bấm gì cả. Đó là cốt lõi. Mọi thứ còn lại là hạ tầng phục vụ cho điều đó.

Phạm Vi Dự Án

PoC Proof of Concept

5 chức năng cốt lõi bắt buộc phải có để chứng minh tính khả thi:

  • GPS Tracking thời gian thực
  • Geofence / Kích hoạt điểm thuyết minh
  • Thuyết minh tự động (TTS + Audio)
  • Quản lý dữ liệu POI
  • Map View bản đồ tương tác

MVP Minimum Viable Product

3 chức năng mở rộng nâng cao trải nghiệm:

  • Hệ thống quản trị CMS (Web Admin)
  • Analytics — Phân tích dữ liệu ẩn danh
  • QR Code kích hoạt nội dung

AI Tính Năng Thông Minh

3 chức năng AI tích hợp:

  • Chatbot trợ lý AI 24/7
  • Thuyết minh đa ngôn ngữ tự động
  • Hỗ trợ giao tiếp đa ngôn ngữ

Luồng Hoạt Động Chính

Khách mở App → GPS liên tục → Geofence check → Khoảng cách < Bán kính? → Phát thuyết minh tự động
Khách quét QR → Lấy POI ID → Phát ngay (không cần GPS)
Khách hỏi AI → Server Ollama → Trả lời + Dẫn đường

PoC — Chức Năng Bắt Buộc (Proof of Concept)

PoC 1 GPS Tracking Thời Gian Thực

📍 Mô tả

Hệ thống liên tục đọc tọa độ GPS của điện thoại khách — kể cả khi app chạy ngầm. Đây là nền tảng của toàn bộ dự án.

  • Android: Foreground Service (GpsForegroundService)
  • iOS: CLLocationManager với quyền always
  • Vòng lặp 3 giây đọc vị trí
  • Gửi qua WeakReferenceMessenger

⚙️ Technical Details

  • Interface: IGpsService
  • Implementation: GpsService.cs
  • Android: ForegroundService.TypeLocation + notification channel
  • iOS: Info.plist — UIBackgroundModes: location
  • Permissions: ACCESS_FINE_LOCATION, ACCESS_BACKGROUND_LOCATION, FOREGROUND_SERVICE_LOCATION

PoC 2 Geofence / Kích Hoạt Điểm Thuyết Minh

🎯 Mô tả

Mỗi quán ăn (POI) được cài đặt:

  • Tọa độ: Latitude / Longitude
  • Bán kính kích hoạt: mặc định 15m
  • Cooldown: 60s (nghe rồi thì 60s mới kích hoạt lại)
  • Mức ưu tiên: Priority (0-1000), cao phát trước

⚙️ Haversine Formula

Tính khoảng cách thực giữa 2 tọa độ GPS trên bề mặt trái đất:

  • GeoMath.Haversine(lat1, lon1, lat2, lon2)
  • R = 6,371,000 mét (bán kính trái đất)
  • Kết quả: khoảng cách tính bằng mét
  • GpsRadiusMultiplier — điều chỉnh độ nhạy

📊 Sequence Diagram — Geofence Trigger

sequenceDiagram
    participant GPS as GpsService
    participant VM as MainViewModel
    participant GF as GeofenceService
    participant NS as NarrationService
    participant API as ApiService

    loop Every 3 seconds
        GPS->>VM: LocationUpdatedMessage
        VM->>GF: CheckTriggeredAsync(location, pois)
        GF->>GF: Haversine distance calc
        GF->>GF: Check cooldown
        GF->>GF: Sort by Priority
        alt distance < radius AND not in cooldown
            GF-->>VM: List of triggered POIs
            VM->>NS: EnqueueAsync(poi, language)
            VM->>API: LogHistoryAsync GPS_TRIGGER
        else
            GF-->>VM: Empty list
        end
    end

📊 State Diagram — POI Geofence State

stateDiagram-v2
    [*] --> Idle: App khởi động
    Idle --> InRange: distance < radius

    Playing --> Idle: User dừng audio

PoC 3 Thuyết Minh Tự Động (Narration Engine)

🔊 Chiến Lược Phát Âm Thanh

Ưu tiên theo thứ tự:

  • 1. File audio thu sẵn theo ngôn ngữ (PoiTranslation.AudioUrl)
  • 2. File audio tiếng Việt thu sẵn (Poi.AudioViUrl)
  • 3. TTS — Text-to-Speech fallback (MauiTtsService)

🎵 Queue Management

  • SemaphoreSlim — chống race condition
  • Queue FIFO — xếp hàng, phát lần lượt
  • Không phát trùng (kiểm tra POI ID)
  • Tự dừng khi StopCurrentAsync()
  • Android: AudioFocusHelper — dừng khi có thông báo

PoC 4 Quản Lý Dữ Liệu POI

💾 Storage Strategy

  • SQLite (offline): LocalDbService — cache trên điện thoại
  • PostgreSQL (online): Database chính, đồng bộ qua API
  • ConnectivityService: Auto-sync khi WiFi kết nối lại

📦 POI Data Model

  • Tên, Mô tả văn bản
  • Tọa độ GPS (lat/lon)
  • Vị trí grid (MapX/MapY 0-100%)
  • Bán kính, Cooldown, Priority
  • Ảnh minh họa, Audio, QR Code
  • Bản dịch đa ngôn ngữ (PoiTranslation)

MVP 3 QR Code Kích Hoạt Nội Dung

📱 Mô tả

  • In QR tại điểm dừng xe bus, bảng hiệu
  • Quét → nghe ngay, không cần GPS
  • Format: VK-POI-{id}
  • Cooldown 2 giây chống spam
  • Server generate QR image (QRCoder)

⚙️ Implementation

  • Mobile: ZXing.Net.MAUI scanner
  • QrViewModel: parse code → load POI → narrate
  • API: GET /api/poi/qrcode/{code}
  • API: GET /api/poi/{id}/qrcode → PNG image

AI Features — Tính Năng Thông Minh

AI 1 Chatbot 24/7

Trợ lý AI tích hợp trong app, biết toàn bộ danh sách quán và vị trí. Hỏi "tôi muốn ăn bánh canh ở đâu?" → AI chỉ đường.

  • System prompt chứa context POI + Tour
  • Ollama local (PoC) / Azure OpenAI (production)
  • Lưu history chat (max 10 messages)

AI 2 Đa Ngôn Ngữ TTS

7 ngôn ngữ: Việt, Anh, Trung, Hàn, Nhật, Khmer, Thái.

  • MAUI native TTS (miễn phí)
  • Azure Cognitive TTS (giọng neural)
  • VoiceRSS fallback option
  • Rate = 0.85 (nói chậm 15% ngoài phố)

AI 3 Giao Tiếp Đa Ngôn Ngữ

Khách hỏi tiếng Anh → AI trả lời tiếng Anh. System prompt tự động:

  • Nhận diện ngôn ngữ người dùng
  • Trả lời bằng ngôn ngữ đó
  • Dẫn đường khu vực theo loại món

Database Schema & Models

Table Primary Key Mô Tả Indexes
Pois Id (int) Điểm quan tâm — quán ăn, khu vực Lat+Lon, Category, QrCode (unique), OwnerUserId, ContentVersion
PoiTranslations Id (int) Bản dịch đa ngôn ngữ cho POI PoiId+LanguageCode (unique)
PoiVisitLogs Id (int) Log lượt nghe thuyết minh VisitedAt
AppUsers Id (int) Tài khoản Admin/Owner Username (unique)
Tours Id (int) Tour lộ trình tham quan —
TourStops Id (int) Điểm dừng trong tour TourId+StopOrder (unique)
TourTranslations Id (int) Bản dịch cho tour TourId+LanguageCode (unique)
MovementLogs Id (long) GPS path ẩn danh (analytics) RecordedAt, SessionId
AppHistoryLogs Id (long) Event log hệ thống CreatedAt, EventType
